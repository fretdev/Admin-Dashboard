# Admin Dashboard

A fully responsive, modern Admin Dashboard built as part of The Odin Project curriculum. This project focuses on mastering advanced CSS layout techniques using CSS Grid and Flexbox, structured around a desktop-first design with clean mobile responsiveness.

## Features

* Macro Grid Layout built with a structured sidebar, sticky top header, and a scrollable main content area.
* Interactive dashboard widgets featuring project cards with action triggers, live announcements, and a trending profiles section.
* Responsive drawer menu including a hamburger toggle menu that transforms the sidebar into a smooth slide-out drawer on smaller mobile screens.
* Custom styling using clean custom typography (Inter / Roboto) and custom SVG icon assets.

## Built With

* HTML5 (Semantic markup)
* CSS3 (CSS Grid, Flexbox, Sticky positioning, Media Queries)
* Vanilla JavaScript (For mobile sidebar toggle functionality)
